# 实时预警：股价触及60周线推送系统 — 需求规格

**版本**：v1.0.0（2026-10-14）
**状态**：需求已与用户逐项确认（两轮选择题），待实现
**关联文档**：`docs/研究方案规格_v1.1.0.md`（事件定义与回测口径的母文档）

---

## 1. 一句话需求

盘中自动发现「股价自下方上穿 60 周线」的 A 股股票，将带基本信息与回测参照的推送发到用户微信，点击可跳转同花顺 App 对应个股行情页。

## 2. 已确认的需求决策（用户逐项选择）

| # | 决策项 | 用户选择 |
|---|--------|----------|
| 1 | 触发时机 | **盘中 + 收盘双轨**：盘中每小时扫描发「预警」，15:15 收盘后发「确认」汇总 |
| 2 | 推送渠道 | **Server酱**（微信推送，用户提供 SendKey） |
| 3 | 推送范围 | **只推 A 类上穿**（B 类回踩不推） |
| 4 | 跳转方式 | **URL Scheme 唤起同花顺 App + 网页版兜底** |
| 5 | 扫描频率 | **每小时一次**（交易时段内 4 次） |
| 6 | 推送内容 | **详细版（带回测参照）** |
| 7 | 触发阈值 | **严格口径**：现价 ≥ 60周线即触发，与回测 Type A 完全一致 |

## 3. 核心判定口径（与回测口径严格对齐）

### 3.1 盘中预警（A 类上穿，实时版）

```
MA60_prev = 上一已完成交易周的 MA60（基于周收盘，后复权）
昨收   C(t-1) < MA60_prev
现价   P(t)   ≥ MA60_prev        ← 严格口径，不加缓冲带
```

- `MA60_prev` 每天开盘前计算一次，当日固定不变（无未来函数）
- 后复权口径与回测一致（baostock adjustflag=1）

### 3.2 收盘确认（15:15）

```
当日收盘 C(t) ≥ MA60_prev 且 昨收 C(t-1) < MA60_prev
```

- 对盘中已推的股票：合并进确认批，标注「盘中已预警」
- 盘中未触发、收盘才触发的：标注「收盘新触发」

### 3.3 去重规则（PM 决策，标注待用户复核）

- 同一股票**同一天**只推一次（盘中与确认批合并计数）
- 同一股票**同一周**内跌回又再次上穿：默认**不重复推**（可配置 `dedup_weekly: true`）

## 4. 数据架构

| 数据 | 来源 | 更新时机 | 用途 |
|------|------|----------|------|
| 60周线 MA60 | baostock（现有建库管线，已验证复权口径） | 每日 16:00 增量更新 | 判定基准 |
| 盘中现价 | 腾讯/新浪免费批量行情接口 | 扫描时拉取（全A每次约5~10个HTTP请求） | 触发判定 + 现价/涨幅 |
| 申万行业/市值 | 现有 `data/industry.csv.gz`、事件库 | 复用 | 推送内容 |
| 回测参照 | 现有 `output/study_result.json` | 复用 | 同类型事件历史胜率 |

**前提依赖**：全A股建库（进行中，预计今日内完成）须先落地，预警系统在其之上运行。

## 5. 推送内容模板（详细版）

```
【60周线上穿预警】宁德时代 300750
现价 251.30（+3.2%）| 超越60周线 +0.8%
─────────────────
行业：电力设备 | 市值：大盘
60周线方向：向上 | 均线排列：多头
今日量比：2.1x | 近一年首次上穿：是
─────────────────
回测参照（沪深300样本，A类上穿）：
  20日 胜率61% 均值+3.5% | 60日 胜率58% 均值+8.1%
  120日 胜率59% 均值+14.2% | 250日 胜率58% 均值+24.0%
👉 [同花顺查看周K](跳转链接)
```

- 量比 = 当日成交量(估算) / 近20日日均；盘中成交量按时段线性外推，标注为估算值
- 「近一年首次上穿」：查事件库近250个交易日内无 A 类事件则为「是」
- 回测参照数字来自已完成的回测结论，随全A回测完成自动更新

## 6. 同花顺跳转方案

**主方案**：URL Scheme 唤起 App（候选，需在用户手机实测）：

1. `hexin://stock/600519` 形态（同花顺主 App）
2. 同花顺 android intent / iOS 万能跳转形态

**兜底**：`https://stockpage.10jqka.com.cn/600519/`（同花顺网页行情，100%可用，页面内可引导打开App）

**验收标准**：用户手机点击链接 → 唤起同花顺且定位到该股行情页（含周K切换入口）。实测不通过则降级为兜底方案并告知用户。

## 7. 运行方式

- 常驻 Python 脚本（`src/alert/` 模块），Windows 计划任务/手动启动
- 每日流程：开盘前更新 MA60 → 10:05 / 11:05 / 14:05 / 14:55 扫描推送 → 15:15 收盘确认批 → 16:00 增量更新行情库
- 推送失败自动重试 3 次；当日推送记录落盘 `output/alert_log/`，防止重启后重复推送

## 8. 非功能需求

- 全A一轮扫描 ≤ 60 秒（批量行情接口）
- 单条推送延迟：触及后 ≤ 65 分钟内送达（每小时扫描粒度）
- 静默约束：非交易时段不扫描；节假日遵循交易日历（baostock）
