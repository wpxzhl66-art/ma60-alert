# 云端部署指南：GitHub Actions 免费定时推送

**版本**：v1.0.0（2026-10-14）
**前提**：全A股建库已完成，`store/` 数据仓已播种并随代码入库

## 架构

```
GitHub Actions（云端，免费）
  交易日 10:05 / 11:05 / 14:05 / 14:55  →  扫描 → 出周K图 → 提交图表 → 推送微信
  交易日 15:15                          →  收盘确认批（空触发也推）
  交易日 16:00                          →  baostock 增量更新 store/ → 提交
  休息日/节假日                          →  交易日历校验，自动跳过
```

- 仓库里只放精简数据仓 `store/`（约 5 MB）+ 代码；全量日线留在本地
- 周K图经 **jsDelivr CDN**（国内微信内可访问）展示在推送里
- SendKey 走 GitHub **Secrets**，不进代码仓库

## 你需要做的（一次性，约 10 分钟）

1. **注册/登录 GitHub**（github.com）
2. **新建仓库**：右上角 + → New repository → 名字如 `ma60-alert` → 选 **Public**（私仓免费时长也够用，但公仓最省心）→ 不要勾选任何初始化文件
3. **本地推送代码**（在本项目目录打开命令行）：
   ```bash
   git config --global user.name "你的名字"
   git config --global user.email "你的邮箱"
   git init
   git add .
   git commit -m "init: 60周线预警系统"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/ma60-alert.git
   git push -u origin main
   ```
   （推送时要求登录，按提示用浏览器授权即可）
4. **配置密钥**：仓库页 → Settings → Secrets and variables → Actions →
   New repository secret → Name 填 `ALERT_SENDKEY`，Value 填你的 SCT 开头密钥
5. **改图表地址**：编辑仓库里的 `config/alert_config.yaml`，把
   `chart_base_url` 的 `USER/REPO` 改成 `<你的用户名>/ma60-alert`
6. **启用并验证**：仓库 Actions 页 → 启用 workflows → 选「60周线预警」→
   Run workflow → task 选 `demo` → 运行日志无红色即部署成功

之后每个交易日自动运行，你只管收微信。

## 验证清单

- [ ] Actions 手动跑 `demo` 成功，产物里有 pending.json 和 charts/*.png
- [ ] 周一 10:05 后收到盘中预警（如有触发）或 15:15 收盘确认
- [ ] 推送里的周K图片能显示（jsDelivr 偶发慢，等几秒）
- [ ] 点击「同花顺行情页」链接打开个股页

## 已知边界

- GHA 定时器可能有 0~10 分钟延迟（官方行为），预警时效相应后移
- Server酱免费额度 5 条/天：4 次盘中扫描中只有「有触发」才推，
  加收盘确认共 ≤5 条，天然不超限
- 新上市股票不会自动进入预警范围（store 播种时快照定死）；
  需要时在本地重跑 `seed_from_local()` 并提交一次即可
- 换电脑/换密钥：只需更新 Secrets 与 `alert_config.local.yaml`

## 本地模式仍然可用

本机常跑回测/研究时，也可直接 `python -m alert.run_alert --daemon`
（电脑开机为前提）。云端与本地互不干扰。
