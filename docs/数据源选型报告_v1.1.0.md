## 二、复权实现正确性：决定性判据

### 判据原理

比例复权的复权因子 = 后复权价 / 不复权价。该因子**只在除权除息日跳变，其余交易日恒定**，必然是一个阶梯函数。若因子每天都在变，说明该源用的不是标准比例复权，其收益序列被系统性扭曲。

### 实测结果（贵州茅台，2018-01-02 ~ 2026-10-13，2127 个交易日）

| 指标 | baostock | akshare（东方财富） |
|---|---|---|
| 唯一因子值个数 | **14 个** | 2049 个 |
| 因子发生变化的天数 | **13 天（0.6%）** | 2118 天（99.6%） |
| 因子最长恒定连续天数 | **251 天** | 2 天 |
| 判定 | **标准比例复权 ✅** | **非比例复权 ❌** |

### baostock 的 13 个因子跳变日（应精确对应真实除权日）

```
2018-06-15  2019-06-28  2020-06-24  2021-06-25  2022-06-30  2022-12-27
2023-06-30  2023-12-20  2024-06-19  2024-12-20  2025-06-26  2025-12-19
2026-06-26
```

全部落在每年 6 月（年度分红）与 12 月（中期分红），与贵州茅台的历年除权除息安排完全吻合。**因子在两次除权之间恒定 251 天**，这正是正确实现的特征。

## 三、三方数据源对比

| 维度 | westock（已弃用） | baostock（选用） | akshare |
|---|---|---|---|
| 复权实现 | 加法前复权 → 历史价为负 | **标准比例复权** | 非比例复权，因子日度漂移 |
| 历史深度 | 日线可回溯 2010 | **2001 年至今** | 2010 年至今 |

| 用途定位 | 弃用 | **主数据源** | 仅取股票清单与指数成分 |

## 四、baostock 覆盖退市股票的实证

| 退市标的 | 取到条数 | 区间 |
|---|---|---|
| 邯郸钢铁 `sh.600001`（2009年退市） | **2885 条** | 1998-01-22 ~ 2009-12-29 |
| PT金田A `sz.000003`（2002年退市） | **2698 条** | 1991-07-03 ~ 2002-06-14 |

**意义**：这是本项目最重要的改进。westock 无法提供退市股票数据，导致「全A股不剔除」在事实上无法实现、生存者偏差不可消除。改用 baostock 后，该偏差**可以从数据层面消除**，而不再只是一个"需要披露的局限"。

## 五、baostock 额外提供的关键字段

这些字段解决了原方案中三项只能标注为"待定"的分层需求：

| 字段 | 解决的方案问题 |
|---|---|
| `turn` 换手率 | 反推**事件时点流通市值**（`amount / (turn/100)`），使市值风格分层不再有前视偏差 |
| `isST` | 支撑 ST 分层——不需人为剔除即可单独统计并对比 |
| `tradestatus` | 精确识别停牌，正确处理停牌周 |
| `peTTM` / `pbMRQ` | 支撑估值分层（可作为附加维度） |

## 六、残余局限（需在研究报告中披露）

1. **行业分类为证监会标准**。baostock 的 `query_stock_industry` 提供的是证监会行业门类/大类，而非申万一级。若坚持申万一级分类，需另行取得分类表（存在归类误差，且历史分类会变动）。
2. **baostock 不提供指数成分股清单**。沪深300 成分股改由 akshare 的指数官网接口获取。
3. **单次查询约 4000 条上限**。全历史取数必须按年分段（已在数据源层实现）。
4. **session 非线程安全**。并行取数须每进程各自登录，不能共享 session。
5. **交易成本未计入**。所有收益为税前毛收益，不含佣金与冲击成本。

## 七、对研究方案的影响

| 方案项 | v1.0.1 状态 | v1.1.0 状态 |
|---|---|---|
| 复权口径 | 被迫降级为「后复权 + 声明缺陷」 | **标准后复权，无需降级** |
| 股票池 | 「不剔除」名义可行、实质不可行 | **实质可行（含退市股）** |
| 样本期 | 需日线合成周线 | 同（baostock 日线同样需合成周线） |
| 市值风格分层 | 标注为「依赖 iFinD」 | **可由换手率反推，自主完成** |
| ST 分层 | 需依赖股票池剔除约定 | **可由 isST 字段直接分层** |
| iFinD 依赖 | 关键路径 | **降级为可选的第三方校验源** |

**结论：iFinD 不再是关键路径。** 原计划等待用户配置 iFinD 密钥，现改为可选——若后续希望做第三方独立校验，再配置即可，不阻塞研究推进。
