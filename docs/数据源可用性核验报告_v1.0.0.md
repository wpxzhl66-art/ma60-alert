# 数据源可用性核验报告

- **版本**：v1.0.0
- **日期**：2026-10-13
- **核验对象**：westock CLI（主数据源）
- **压力测试样本**：`sh600519` 贵州茅台
- **选样理由**：上市时间长（2001年至今）、累计分红规模大，是复权处理逻辑的压力测试极值样本。复权逻辑若存在缺陷，在此样本上最先暴露。

---

## 一、核验结论（先行）

**该数据源目前不足以支撑「2010年至今、全A股、复权收益」的严谨事件研究。**

核心依据只有一条：**同一只股票、同一段行情，两种复权口径给出的累计收益相差 88.50 个百分点**（+204.23% vs +115.73%）。在 8.8 年的长周期上，这一差异远超任何合理的研究误差范围，会使研究结论完全取决于口径选择，而非市场规律本身。

---

## 二、逐项发现与证据

### 发现 1：默认口径与后复权口径互相矛盾（致命）

| 指标 | 默认口径（= `--fq qfq`） | 后复权（`--fq hfq`） |
|---|---|---|
| 2018-01-02 收盘 | 419.05 | 4161.65 |
| 2026-10-13 收盘 | 1274.89 | 8978.10 |
| **累计收益** | **+204.23%** | **+115.73%** |
| **两者之差** | **-88.50 个百分点** | |

后复权的累计收益**低于**默认口径，这在逻辑上不可能——正确的复权处理必须使后复权累计收益 ≥ 未复权累计收益（差额即累计分红收益）。当前结果说明至少有一方实现有误。

### 发现 2：默认口径在长历史上产生负价格

```
2010-01-04  默认口径收盘 = -188.89    ← 负值
2010-01-29  默认口径收盘 = -189.95    ← 负值
2010-01-04  后复权收盘   =  740.26    ← 正值
```

负价格意味着默认口径采用了**加法复权**（历史价 = 原价 − 累计分红），而非标准的比例复权。加法复权会导致：
- 历史价格为负，均线计算失效
- 收益率失真（分母可能跨越零点），这是其累计收益虚高至 +204% 的根因

**结论：默认口径（= `--fq qfq`）在长周期上不可用。**

### 发现 3：后复权序列亦存在内部不一致

在 **2026-09-01 至 2026-10-13** 这段**不含任何除权除息事件**的窗口内，`后复权/默认口径` 的比值仍从 6.9836 波动至 7.0873（**幅度 1.48%**）。复权因子在无除权事件时应严格恒定。

同一日内 OHLC 缩放也不一致（2026-10-13）：

| 字段 | 默认口径 | 后复权 | 比值 |
|---|---|---|---|
| 收盘 | 1274.89 | 8978.10 | 7.0423 |
| 最高 | 1288.48 | 9054.58 | 7.0273 |
| 最低 | 1268.11 | 8939.94 | 7.0498 |

同一交易日的四个价格应按同一因子缩放，实际比值离散达 0.32%。

### 发现 4：复权因子随时间的漂移

`后复权/默认口径` 比值从 2018 年的 9.93 单调衰减至 2026 年的 6.94，**波动幅度 100.79%**。正确实现下该比值只应在除权日阶梯式跳变，而非连续漂移。

### 发现 5：退市股票完全无数据（生存者偏差不可消除）

| 测试标的 | 结果 |
|---|---|
| `sh600001` 邯郸钢铁（已退市） | 数据为空 |
| `sz000003` 已退市标的 | 数据为空 |

**影响**：用户选择的「全A股不做任何剔除」在事实上无法实现。历史股票池中已退市的标的不可获取，研究样本天然只包含"活到今天"的股票，会系统性高估收益。这是本项目**无法通过技术手段消除**的偏差，只能显式披露。

### 发现 6：接口间歇性静默返回空

同一分段请求 `2018-01-01 ~ 2019-12-31`，首次返回 0 条，连续重试 3 次均返回 487 条。接口在超时后**静默返回空结果而非报错**（首次成分股查询曾明示 `context deadline exceeded`）。

**影响**：全A股约 5400 只标的的批量取数必须内置「重试 + 条数校验」，否则会产生难以察觉的大面积数据缺失。

### 发现 7：周期数据的能力边界

| 周期 | 回溯上限 | 可用性 |
|---|---|---|
| 周线 | **264 条**（约5年，最早 2021-08-20） | 提升 `--limit` 无效，**硬上限** |
| 日线 | 提高 `--limit` 至 5000+ 可回溯至 **2010 年** | 可用（约4055条） |
| 月线 | 124 条，且出现负开盘价与 469% 单月涨跌幅 | **不可用** |

**影响**：直接取周线无法满足「2010年至今」的样本期。必须以**日线合成周线**（`HF_week = last(日线HF)`）。

### 发现 8：CLI 行为细节（工程注意项）

- `--limit N` 的语义是「返回最近 N 条」，**会覆盖 `--start` 的下限约束**
- `--end` 传入未来日期会直接返回空
- `--fq bfq` 为无效取值（不复权需省略该参数），且省略后的默认口径 = 加法前复权（见发现 2）

## 三、对研究方案的影响

| 原方案设定 | 受影响程度 | 说明 |
|---|---|---|
| 样本期 2010年至今 | ⚠️ 可达成 | 必须走「日线合成周线」路径 |
| 全A股不剔除 | ❌ 无法达成 | 退市股不可得，生存者偏差不可消除 |
| 三重基准复权收益 | ❌ 受阻 | 两种复权口径矛盾达 88.5pp，需第三方数据裁定 |
| 20/40/60/120/250 日窗口 | ⚠️ 可达成但存疑 | 需可靠复权序列支撑 |

---

## 四、建议路径

**首选**：以 **iFinD（同花顺专业数据）** 作为主数据源。理由：专业金融终端对复权处理有成熟实现与行业认可，且可提供退市股票历史数据（消除生存者偏差）。westock 保留为辅助源，用于抽样交叉校验。

**次选**：由用户提供本地数据文件（最可控，且可预先确认口径与覆盖范围）。

**若坚持使用 westock**：必须选定 `hfq` 后复权口径（唯一价格为正、可覆盖全期的序列），并在报告中声明：① 复权实现存在已证实的内在一致性缺陷；② 生存者偏差不可消除；③ 结论强度应下调。
