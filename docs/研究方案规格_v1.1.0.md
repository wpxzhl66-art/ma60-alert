## 一、研究目标

量化回答一个问题：**A股个股股价触及60周均线后，未来一段时间的表现如何？**

具体拆解为三个可检验的子问题：

1. 触及后 20 / 40 / 60 / 120 / 250 个交易日的平均收益与胜率是多少？
2. 该表现相对沪深300与所属申万一级行业指数，是否存在超额收益？
3. 该表现如何随「60周线方向」「均线排列」「市场环境」「板块与市值风格」而变化？

## 三、事件定义（精确化）

设第 t 周的周收盘价为 `C(t)`，60周均线为 `MA60(t) = mean(C(t-59) … C(t))`，
带宽 `B(t) = MA60(t) × (1 ± 2%)`。

### 事件类型 A —「上穿突破」（趋势反转候选）

同时满足：
- `C(t-1) < MA60(t-1)`（事件前一周在均线下方）
- `C(t) ≥ MA60(t)`（本周站上均线）

含义：趋势由弱转强的突破信号。

### 事件类型 B —「上方回踩触及」（趋势中继候选）

同时满足：
- `C(t-1) ≥ MA60(t-1)`（事件前一周已在均线上方）
- `C(t)` 落入带宽区间 `[MA60(t)×0.98, MA60(t)×1.02]`（本周回落触及均线）
- `C(t) ≥ MA60(t)×0.98`（未有效跌破，即未跌破下轨）

含义：上升趋势中对均线支撑的测试。

### 共同约束

- 事件成立要求 `t ≥ 60`（可用周数不足60周无法计算均线，此类标的**天然被排除**，属计算前提而非人为剔除选择，需在报告中说明）。
- 两类事件**分别建表、分别统计**，不合并。

## 四、评估体系

### 4.1 收益计算

以事件周收盘价 `P0 = C(t)` 为基准（事件周最后交易日收盘）。

| 窗口 N | 终点 | 收益口径 |
|---|---|---|
| 20 / 40 / 60 / 120 / 250 交易日 | `P1 = C(t+N)` | 见下 |

- **绝对收益**：`R_abs = P1 / P0 - 1`
- **相对沪深300**：`R_ex_hs300 = R_abs - R_hs300(同期)`
- **相对申万一级行业**：`R_ex_ind = R_abs - R_ind(同期)`
- **价格口径**：统一使用**后复权**周收盘价（baostock `adjustflag=1`）。该源的复权因子经判据验证为**标准阶梯函数**——14 个取值、最长恒定 251 天、跳变日精确对应真实除权日，收益序列可信。必须复权，否则除权跳空会污染均线位置与收益连续性。

### 4.2 统计指标

对每个（事件类型 × 窗口 × 分层）单元输出：

- 样本量 N
- **均值**与**中位数**（A股收益分布右偏，中位数常与均值背离，必须同时给出）
- 标准差
- **绝对胜率**（R_abs > 0 占比）与**超额胜率**（R_ex > 0 占比）
- **盈亏比**（窗口内平均盈利 / 平均亏损绝对值）
- 分位数（10% / 25% / 50% / 75% / 90%）
- **MFE / MAE**：窗口内最大浮盈 / 最大浮亏（用于评估持有体验与止损设置）
- **最大回撤**（窗口内）

## 五、分层规则（默认阈值，可调）

| 分层维度 | 判定规则 |
|---|---|
| **60周线方向** | `slope = MA60(t) / MA60(t-13) - 1`（13周≈1季度）。向上：> +1%；走平：-1% ~ +1%；向下：< -1% |
| **均线排列** | 周线 MA5 > MA10 > MA20 > MA60 为「多头排列」；否则为「非多头排列」 |
| **事件前位置** | 类型 A 天然为「线下→线上」；类型 B 为「线上回踩」 |
| **市场环境** | 以沪深300 与其40周均线关系判定：<br>牛市 = 指数在MA40上方 且 MA40向上<br>熊市 = 指数在MA40下方 且 MA40向下<br>震荡 = 其余 |
| **市值风格** | 按**事件时点**的流通市值分位数分档（避免前视偏差）：大盘 Top 30%、中盘 30%~70%、小盘 Bottom 30% |
| **板块** | 申万一级行业（31个） |

> 所有阈值集中存放于 `config/study_config.yaml`，可单点修改后全流程重跑。

## 六、数据与工程

### 6.1 数据需求

| 数据 | 用途 | 频率/范围 |
|---|---|---|
| 全A股周K线（前复权，含OHLCV） | 计算60周线、判定事件、计算收益 | 周频，2010-01-01 至今 |
| 全A股标的清单（含上市日期、行业、市值、ST标记） | 股票池与分层 | 截面 + 历史标记 |
| 沪深300指数周线 | 市场基准 + 市场环境判定 | 周频 |
| 申万一级行业指数周线（31个） | 行业基准 | 周频 |

### 6.2 处理链路

```
取数（API） → 本地建库（Parquet/SQLite）
  → 计算 MA60 与带宽
  → 事件检测（类型A / 类型B）
  → 关联基准（沪深300 / 行业指数）
  → 计算 5 窗口 × 3 收益口径
  → 打分层标签（4 维度）
  → 统计汇总 → 报告 / 明细 / 图表
```

### 6.3 停牌与缺失处理

- 全市场交易日序列对齐，停牌周以最近可得收盘价前值填充。
- 明细中标注每笔事件的停牌周数；停牌周数 > 窗口 20% 的样本单独标记。

## 七、已知局限与风险声明（必须在报告中显式披露）

1. ~~**生存者偏差**~~ → **已在数据层面消除**。baostock 完整覆盖退市股票（实测：邯郸钢铁 2885 条、PT金田A 2698 条），「全A股不剔除」由名义口径变为实质可达。历史股票池不再只含"活到今天"的标的。
2. **样本重叠**：本方案采用「不去重」口径，同一段行情会被重复计数，样本不独立，统计显著性名义值偏高。报告中须给出：① 每只股票贡献的事件数分布；② Top 10 股票占样本比例；③ **去重后（26周冷却）的对照结果**。
3. **统计显著性口径**：因样本不独立，常规 t 检验不适用。将采用**按股票聚类（cluster）的稳健标准误**或**按股票分组的 Bootstrap** 评估显著性。
4. **涨跌停与ST**：ST股 ±5% 限制会压缩收益分布，低估波动。标注并输出剔除ST后的敏感性对比。
5. **次新股**：不足60周无法计算均线，天然排除，非人为剔除。
6. **行业分类口径差异**：baostock 提供证监会行业分类，而非申万一级。若需申万一级，须另行取得分类表，存在归类误差（且历史分类会变动）。
7. **交易成本未计入**：所有收益为税前、不含佣金与冲击成本的毛收益。
8. **无未来函数约束**：所有分层标签（含市值、行业）必须使用事件时点可得的信息，禁止使用全期静态数据。
